# vanilla JS 4 days Course.

## Day 1: Introduction to JavaScript (Agenda)

- Introduction to JavaScript and its history
- Setting up the development environment
- Basic syntax and structure
- Basic input and output (console.log, prompt)
- Variables (literal creation vs constructor creation) and data types
- implicit and explicit type conversion
- Basic operators (arithmetic, assignment, comparison, logical)
- short circuit,  and expressions
- Control flow (if statements, switch statements)
- Loops (for, while, do-while)
- break and continue statements
